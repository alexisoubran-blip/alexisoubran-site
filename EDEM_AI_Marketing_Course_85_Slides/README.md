# IA para líderes de marketing — EDEM

Presentación web de cinco horas impartida por Alexis Soubran, CEO de Minimalist.

## Controles

- Flechas: avanzar o retroceder
- `Esc`: vista general
- `S`: presenter mode con notas
- `F`: pantalla completa
- Botón `ARSENAL`: directorio actualizado de herramientas
- Botón `PDF`: versión lista para imprimir desde Chrome

## Desarrollo

```bash
npm install
npm run dev
```

## Validación y build

```bash
npm run check
npm run build
```

El sitio conserva respuestas de ejercicios en el navegador mediante `localStorage`.
