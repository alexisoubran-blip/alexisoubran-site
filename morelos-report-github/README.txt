Cómo publicarlo:
1. Descomprime este ZIP.
2. En GitHub abre el repositorio alexisoubran-site.
3. Selecciona Add file > Upload files.
4. Arrastra la carpeta reportes completa.
5. Haz commit directamente a main.
6. Espera el deployment automático de Vercel.

Ruta esperada:
https://alexisoubran.com/reportes/mundial-morelos/

Nota:
El reporte contiene información comercial. Si el repositorio es público,
el HTML y los datos embebidos también serán públicos.
