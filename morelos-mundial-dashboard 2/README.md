# Dashboard Mundial 2026 — Supermercados Morelos

Sitio estático listo para GitHub Pages.

## Publicación
1. Sube el contenido de esta carpeta a un repositorio.
2. En GitHub abre **Settings → Pages**.
3. Selecciona **Deploy from a branch**.
4. Elige la rama `main` y la carpeta `/root`.
5. Guarda. GitHub publicará `index.html` automáticamente.

## Estructura
- `index.html`: dashboard y datos.
- `assets/css/morelos-brand.css`: identidad visual y responsive.
- `assets/js/morelos-brand.js`: encabezado de marca.

No requiere build, Node.js ni servidor. Funciona como sitio estático.
